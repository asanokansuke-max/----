# 百万石フットボール

金沢の弱小サッカークラブを率いて、北信越リーグから J1 の頂点を目指すクラブ経営シミュレーションゲーム。

`index.html` をブラウザで開くだけで遊べます（ビルド不要・外部依存なし）。進行状況はブラウザの localStorage に自動保存されます。

## あそびかた

- 1シーズン18節。毎週「作戦・練習」で練習メニュー・戦術・フォーメーション・チケット価格・広報活動を決めて「次の試合へ」。
- リーグ（実際のレギュレーションに準拠）：
  - 北信越リーグ2部（8チーム・14節）：1位は1部へ自動昇格、2位は1部7位と入れ替え戦
  - 北信越リーグ1部（8チーム・14節）：優勝（または全社枠）で全国地域サッカーチャンピオンズリーグへ。1次ラウンド（4チーム総当たり）を1位で抜け、決勝ラウンドで2位以内ならJFL昇格。7位は入れ替え戦、8位は2部へ降格
  - JFL（16チーム・30節）：1位はJ3へ自動昇格、2位はJ3の19位と入れ替え戦、15・16位は地域リーグへ降格
  - J3（20チーム・38節）：1・2位は自動昇格、3〜6位でJ2昇格プレーオフ（引き分けは上位進出）、19位はJFL2位と入れ替え戦、20位はJFLへ降格
  - J2（20チーム・38節）：1・2位は自動昇格、3〜6位でJ1昇格プレーオフ、18〜20位はJ3へ降格
  - J1（20チーム・38節）：18〜20位はJ2へ降格
- 昇格にはクラブライセンス（スタジアムのレベル、J3以上はS級監督）が必要です。
- 若手は練習と試合で成長。ユースアカデミーから毎年新人が昇格し、育てた選手を売って資金にすることもできます。
- 兼六園・近江町市場・百万石まつり・金箔ユニフォームなど、金沢ならではのイベントや広報活動でファンを増やしましょう。
- フロントの信頼が0になると解任（ゲームオーバー）。資金のマイナスは信頼を下げます。

## クラブ運営の要素

- **報告（ヘッドコーチ・スタッフ・フロントから）**：出場機会を求める選手、年俸アップ要求、外国籍選手のホームシック、若手の武者修行（期限付き移籍）希望、疲労の蓄積、監督と選手の溝、フロントからの監督交代要求など。選択次第で選手の士気が変わります。2週放置すると自動処理。
- **スタッフ人事**：監督・ヘッドコーチ・フィジカルコーチ・GKコーチ・育成コーチ・チーフスカウト・営業担当を招聘／解任（違約金あり）。監督には得意戦術・人心掌握・ライセンス（S級/A級）があり、J3以上への昇格にはS級監督が必要。実力者ほど下位カテゴリーからの打診を断りがち。
- **高校・大学スカウト**：インターハイ予選、高校選手権県大会、北信越大学リーグなどの結果から活躍選手がリストアップされます。視察するたびに推定能力の幅が約半分になり（視察レポートで前後を表示）、入団の見込みも上がります。内定した高校生は2種登録、大学生は特別指定選手として今季から出場可能（アマチュアのため今季は年俸なし、来季プロ契約）。
- **営業**：地元企業（老舗・中堅・大企業）を営業担当が訪問して関係を深め、ユニフォーム胸・背中・袖、看板、命名権などのスポンサー契約を提案。大企業には出資も依頼可能。年1回のクラウドファンディングも。
- **交渉**：移籍・海外選手・高校大学生へのオファーや契約更新は、移籍金（支度金）・年俸・契約年数を提示して交渉。「交渉中…」の後に合意・逆提案・決裂のどれかが返ってきます。安すぎる提示は相手を怒らせ、交渉の余地が減ります。
- **移籍の種類**：通常の移籍に加え、移籍金0円のフリー移籍（オフには契約満了組が増える）や、上位クラブの若手の期限付き移籍（レンタル料と年俸の半分のみ負担・買取オプションで完全移籍も可）が移籍市場に並びます。
- **海外スカウト**：スタッフとして雇い、南米・東欧・東南アジア/韓国・アフリカへ派遣すると、2〜3週後に「謎の外国人」を連れて帰ってきます。推定能力は幅が広く、獲得して初めて実力が判明。外国籍は5人まで。
- **オフシーズン（10週間・12月〜3月上旬）**：契約更改 → 戦力外通告・移籍交渉 → 合同トライアウト → 高校選手権・新体制発表会（キャンプ地決定） → 自主トレ → チーム始動・メディカルチェック → 春季キャンプ2週（沖縄・宮崎・タイ・金沢、練習試合あり） → プレシーズンマッチ → 開幕前イベントを経て開幕。オフの間も移籍・人事・営業ができます。
- **選手の詳細と契約**：選手一覧の名前か「詳細」から、能力・伸びしろ・調子・士気・成績・契約（種類、年俸、残り年数、市場価値）を確認し、休養・売却・戦力外・契約更新ができます。契約が満了した選手は、オフの12月下旬までに更新しないと退団します（士気が低いと更新を断られることも）。
- **負傷**：打撲・捻挫・肉離れ・膝の靭帯損傷・半月板損傷・疲労骨折・前十字靭帯断裂など、部位と診断名・全治期間のある負傷が起きます。調子が低い・ベテラン・猛練習・再発直後ほど起きやすく、メディカル施設やフィジカルコーチで減らせます。重傷は手術か保存療法か、軽傷は痛み止めで強行出場させるかを選べます。長期離脱明けは試合勘が戻るまで少し力が落ち、選手の詳細でリハビリの進み具合と負傷歴を確認できます。
- **役割**：選手にはポジションごとの役割があります（GK：セーブ型/足元型、DF：ストッパー/カバー/組立CB/攻撃SB/守備SB、MF：アンカー/B2B/司令塔/サイド/トップ下、FW：点取り屋/ポスト/快速/ハードワーク）。今の戦術に合う役割の選手が多いほど、また陣形に欲しい役割（例：4-3-3なら前線に快速か点取り屋）がいるとチーム力が上がります。役割は選手の詳細から変えられます（慣れるまで約4週）。
- スタッフの招聘も、契約金・年俸・契約年数を提示する交渉制です。
- **放出**：選手はボタン一つでは売れません。選手の詳細から「移籍リストに載せる」と、他クラブからオファーが届き（冬と夏の移籍期間は多め）、受け入れる・増額を求める・断るを選べます。主力には移籍リスト外でも引き抜きのオファーが来ることがあり、上のカテゴリーからの話を断ると本人は不満を持ちます。すぐに手放すなら、残り契約に応じた違約金を払って契約解除します（契約満了の選手は無料で更新しないことも可能）。
- **日程**：「日程」タブで、シーズンの試合日程（日付・ホーム/アウェイ・相手の順位・結果）と、学生大会・移籍期間・オフの予定をカレンダー形式で確認できます。
- **年俸**：年俸は契約更新や昇給の要望のときにだけ変わり、1回で上がるのは最大1.6倍までです。実力に対して年俸が低すぎる選手は不満をためます。
- **全国スカウト**：年額を払って全国スカウト網と契約すると、クラブユース選手権・インターハイ・総理大臣杯・インカレ・全国高校選手権の注目選手もリストアップされます（オフの全国大会で内定した選手は開幕から加入）。
- **メニュー**：ホームのメニューは「チーム（選手・作戦）」「編成・人事（移籍市場・高校大学・海外スカウト・スタッフ・スタッフ採用）」「クラブ経営（営業・施設・財務）」「リーグ（順位表・日程・記録）」の4つ。報告はホーム画面で直接返答できます。
- **財務**：今季と前季の収入・支出を項目別（チケット、スポンサー、賞金、移籍金、年俸、施設維持費など）に確認できます。
- **記録**：今季の得点ランキング、現役選手の通算得点・出場、クラブ記録（最高成績、シーズン最多勝点・最多得点）、得点王つきのクラブ史。
- **天皇杯**：J3以下のクラブは5月の石川県サッカー選手権（県予選）から、J1・J2クラブは2回戦から登場。勝ち上がるとJ1クラブとの対戦も。格上を倒すと「大金星」でファン・信頼が上がり、ベスト8以上で賞金。優勝回数は記録に残ります。
- **サポーター団体**：「百万石ゴール裏連合」の熱量は勝敗やチケット価格で上下し、高いほどホームの後押しと観客数が増えます。遠征バスの補助や交流会などの要望、成績不振時の抗議、横断幕の激励が報告として届きます。
- **評価点・MVP**：試合ごとに出場選手へ評価点（4.0〜9.8）が付き、MVPは士気が上がります。選手の詳細と記録で平均評価・直近の評価を確認できます。
- **ダービー**：富山・福井などのクラブがライバルとなり「北陸ダービー」に。観客が増え、勝敗によるファン・士気・サポーターへの影響が大きくなります。
- **下部組織（チーム → 下部組織）**：U-18（高1〜高3）とU-15（中1〜中3）を学年ごとに管理。育成施設・育成コーチ・ユースのリーグのレベルで毎週成長します。U-18はプリンスリーグ北信越2部から始まり、1部、高円宮杯プレミアリーグWESTへと昇降格（シーズン中に毎週1試合）。成績でアカデミーの評判が上がり、入ってくる選手の数と質が上がります。
  - 高3は「トップ昇格」させると生え抜きのプロ選手に。昇格しなかった選手は大学へ進み、有望なら4年後に「ユース出身」の大学生として高校・大学のリストに戻ってきます（入団に前向き）。
  - 中3はU-18に上げるかどうかを選べます。U-18の選手は在籍のまま2種登録してトップの試合に出せます。
  - シーズン終盤には育成コーチから昇格者を決めるよう報告が届きます。
- **能力の内訳**：選手には15の能力（技術：シュート・パス・ドリブル・クロス・ヘディング・タックル／身体：スピード・スタミナ・フィジカル／メンタル：視野・ポジショニング・冷静さ／GK：反応・キャッチング・飛び出し）があり、総合力はポジションごとに重視する能力の重み付き平均です（例：FWはシュート、DFはタックルとポジショニング、MFはパスと視野）。選手の詳細で内訳・長所/短所・今季の増減・他ポジションで起用した場合の力を確認できます。
  - 若手はスピードやスタミナ、ベテランは視野や冷静さが伸び、衰えはスピードとスタミナから来ます。
  - 「作戦・練習」の練習テーマ（バランス・技術・フィジカル・戦術理解）で伸ばす系統を選べます。ポジションで重視される能力に合うほど総合力も伸びます。
  - 役割の適性（◎○△×）は能力から決まり、適性が高いほど役割の効果が大きくなります。ポジション外で起用すると、そのポジションでの総合力で戦います。
  - 移籍市場の選手には「特徴」（得意な能力）が表示されます。
